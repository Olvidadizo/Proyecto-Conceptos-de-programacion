CONCLUSIONES DEL PROYECTO

1. LO APRENDIDO DURANTE EL DESARROLLO DEL PROYECTO


Durante el desarrollo de este proyecto aprendimos a aplicar los conceptos
fundamentales de la programación en Java en un contexto real: la generación
y el procesamiento de archivos planos con información de vendedores,
productos y ventas.

Entre los principales aprendizajes se destacan:

- El uso de funciones y métodos en Java para organizar el código de forma
  modular, reutilizable y fácil de mantener.

- El uso de estructuras de control (ciclos for, condicionales if/else) para
  recorrer y procesar grandes volúmenes de datos.

- La importancia del manejo de excepciones (try-catch) para que el programa
  no falle ante errores de entrada/salida.

- El uso de colecciones como ArrayList, HashSet y Map para almacenar y
  organizar información de manera eficiente.

- La aplicación de buenas prácticas de programación: nombres descriptivos,
  documentación con Javadoc, separación de responsabilidades y uso de
  constantes.

- El trabajo colaborativo usando GitHub para versionar el código y
  compartir avances con el equipo.


2. POSIBLES APLICACIONES EN LA VIDA PROFESIONAL

Los conocimientos y destrezas adquiridos durante este proyecto tienen
aplicación directa en el ámbito profesional, especialmente en áreas como:

- Desarrollo de software empresarial: la generación y procesamiento de
  archivos planos es una tarea común en sistemas de facturación, inventarios,
  nómina y reportes financieros.

- Análisis de datos: la capacidad de leer, transformar y generar archivos
  CSV es fundamental para integraciones con herramientas como Excel, Power BI
  o bases de datos.

- Automatización de procesos: muchos flujos de trabajo en las empresas
  requieren generar reportes automáticos a partir de datos dispersos en
  múltiples archivos.

- Trabajo en equipo: el uso de GitHub nos prepara para colaborar en
  proyectos reales con múltiples desarrolladores.

Este proyecto nos dio una base sólida para enfrentar problemas
reales de programación en cualquier entorno laboral.

3. DIFICULTADES PRESENTADAS DURANTE EL DESARROLLO

A lo largo del proyecto enfrentamos varias dificultades que nos ayudaron a
crecer como programadores:

- Comprender la diferencia entre argumentos y parámetros, y cómo usarlos
  correctamente en los métodos.

- Organizar el código en clases y paquetes de forma coherente, especialmente
  al separar la clase generadora de archivos (GenerateInfoFiles) de la clase
  principal (Main).

- Manejar correctamente las rutas de los archivos, ya que en ocasiones los
  archivos se generaban en carpetas distintas a las esperadas.

- Entender la lógica de ordenamiento de los reportes CSV (vendedores por
  dinero recaudado, productos por cantidad vendida).

- Documentar el código con Javadoc de forma clara y completa, siguiendo los
  estándares del lenguaje.

Estas dificultades fueron superadas gracias a la investigación autónoma, la
consulta de documentación oficial (Oracle), el apoyo entre compañeros y el
uso de herramientas como foros y asistentes de programación.
